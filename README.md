# HTU Internship Portal
A full-stack web platform designed to streamline the internship application process for **Al Hussein Technical University (HTU)** students.

## Tech Stack
* **Backend:** PHP
* **Database:** SQL (MySQL)
* **Frontend:** HTML5, Sass, Bootstrap
* **Design:** Figma

## Key Features
* Student Dashboard to track applications.
* Centralized database for internship opportunities.
* Responsive UI for mobile and desktop.

## Experience & Testing
* Developed during my graduation phase with a focus on clean code and database relations.
* Performed functional testing to ensure system stability.
